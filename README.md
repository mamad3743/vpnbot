# 🤖🛍 بات فروش VPN + مینی‌اپ — نصب یک‌کلیکی، بدون تنظیم متغیر روی Railway

نسخه‌ی دوم این پروژه، دیگه هیچ‌کدوم از تنظیمات کسب‌وکاریت (توکن بات، پنل، عضویت اجباری،
کارت بانکی، رنگ مینی‌اپ...) رو روی Railway وارد نمی‌کنی. همه چیز از یه صفحه‌ی نصب
و بعدش از داخل خود بات تنظیم میشه.

## ✨ چی جدید شده نسبت به نسخه‌ی قبل؟

- 🌐 بات از حالت polling به **وب‌سرور + وبهوک** تبدیل شده (یک پروسه، یک دامنه)
- 🧩 صفحه‌ی **`/install`**: دامنه رو باز می‌کنی، توکن بات و آیدی ادمین رو می‌دی، بات خودکار بالا میاد و وبهوکش خودش ست میشه
- ⚙️ همه‌ی تنظیمات (پنل PasarGuard، عضویت اجباری، کارت بانکی، اکانت تست، رنگ مینی‌اپ) از داخل «پنل مدیریت» توی خود بات قابل تغییرن — بدون نیاز به ریدیپلوی
- 🛍 **مینی‌اپ تلگرامی** واقعی: کاتالوگ فروشگاهی شیک با تم روشن/تیره خودکار (هماهنگ با تم تلگرام کاربر)، رنگ اصلی قابل تنظیم توسط ادمین، نمایش موجودی کیف پول، خرید و دریافت اکانت تست با یک ضربه

## 🏗 معماری

```
main.py            # وب‌سرور aiohttp: /install ، /webhook ، مسیرهای مینی‌اپ و API
miniapp_api.py      # روت‌های JSON برای مینی‌اپ (/api/config ، /api/plans ، /api/me)
miniapp/index.html  # خودِ مینی‌اپ (تک‌فایل، بدون نیاز به build)
settings.py         # لایه‌ی تنظیمات: همه چیز تو دیتابیسه، از داخل بات قابل تغییره
database.py         # SQLite: کاربران، پلن‌ها، سفارش‌ها، کدها، کیف پول، تنظیمات
panel.py            # اتصال به API پنل PasarGuard (آدرس/یوزر/پسورد از settings میاد)
handlers/
  start.py          # /start ، /cancel ، چک عضویت اجباری
  plans.py          # نمایش پلن‌ها + خرید (تابع مشترک perform_purchase)
  trial.py          # اکانت تست رایگان (تابع مشترک create_trial)
  webapp.py         # پردازش داده‌ی ارسالی از مینی‌اپ (sendData)
  wallet.py          # شارژ کیف پول + تایید ادمین
  orders.py         # تاریخچه خرید
  admin.py          # پنل مدیریت کامل (پلن‌ها، کدها، پنل، عضویت اجباری، پرداخت، تم)
```

## 📱 نصب (کل کار از گوشی هم قابل انجامه)

1. کد رو به یه ریپازیتوری گیت‌هاب push کن (همونطور که قبلاً یاد گرفتی).
2. تو Railway پروژه رو از همون ریپو بساز — این بار **هیچ Variable ای لازم نیست بزنی.**
3. برو **Settings → Networking → Generate Domain** تا یه دامنه‌ی `xxx.up.railway.app` بگیری.
4. همون دامنه رو تو مرورگر باز کن — خودش می‌فرسته به `/install`.
5. توکن بات (از BotFather) و آیدی عددی خودت (از @userinfobot) رو وارد کن → **نصب و راه‌اندازی**.
6. تموم! برو تو تلگرام `/start` رو به باتت بزن. منوی «⚙️ پنل مدیریت» همونجا هست؛ از همونجا پنل PasarGuard،
   عضویت اجباری، کارت بانکی، اکانت تست، و رنگ مینی‌اپ رو تنظیم کن.

> ⚠️ **مهم:** چون همه‌ی تنظیمات (حتی توکن بات) داخل دیتابیس SQLite ذخیره میشه، حتماً از تب **Volumes** تو
> Railway یه والیوم به مسیر `/app/data` وصل کن. اگه این کار رو نکنی، با هر ریدیپلوی همه چیز پاک میشه و
> باید دوباره از `/install` شروع کنی.

## 🛍 مینی‌اپ

بعد از نصب، تو منوی اصلی بات یه دکمه‌ی **«🛍 فروشگاه شیشه‌ای»** ظاهر میشه که مینی‌اپ رو باز می‌کنه.
مینی‌اپ به‌صورت خودکار:
- تم روشن/تیره‌اش رو با تم تلگرام کاربر هماهنگ می‌کنه (+ یه دکمه‌ی تغییر دستی هم داره)
- رنگ اصلی دکمه‌ها رو از همون رنگی که تو پنل مدیریت انتخاب کردی می‌گیره
- موجودی کیف پول کاربر رو نشون می‌ده
- خرید و دریافت اکانت تست رو مستقیم از همونجا، با یک ضربه انجام می‌ده (نتیجه به‌صورت پیام تو چت بات براش میاد)

رنگ اصلی مینی‌اپ رو از «⚙️ پنل مدیریت → 🎨 تم و رنگ مینی‌اپ» هر وقت خواستی عوض کن — نیازی به ریدیپلوی نیست.

## 🔧 تست محلی (اختیاری، قبل از دیپلوی)

```bash
pip install -r requirements.txt
python main.py
```
بعد `http://localhost:8080/install` رو باز کن. برای اینکه تلگرام بتونه وبهوک بفرسته باید یه دامنه‌ی
HTTPS عمومی داشته باشی (برای تست محلی می‌تونی از ابزارهایی مثل ngrok استفاده کنی).

## ⚠️ نکات مهم

- **API پنل:** فایل `panel.py` بر اساس پکیج رسمی پایتون `pasarguard` نوشته شده. اگه نسخه‌ی پنل شما
  endpoint یا پارامترهای متفاوتی داشت، مستندات Swagger پنل خودت رو در آدرس `PANEL_URL/docs` چک کن.
- **تایید پرداخت:** شارژ کیف پول فعلاً با ارسال رسید و تایید دستی ادمینه (مناسب کارت‌به‌کارت). برای
  درگاه پرداخت آنلاین (زرین‌پال و غیره) باید یه ماژول جدید اضافه بشه.
- **امنیت نصب:** بعد از اولین نصب موفق، صفحه‌ی `/install` قفل میشه و دیگه کسی نمی‌تونه دوباره نصبش کنه.
- **امنیت وبهوک:** یک secret token تصادفی تولید و روی وبهوک تنظیم میشه؛ درخواست‌هایی که این هدر رو نداشته باشن رد میشن.
