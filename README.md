# 🤖 بات فروش VPN — اتصال به پنل PasarGuard

بات تلگرامی فروش سرویس VPN با اتصال مستقیم به پنل **PasarGuard**، آماده‌ی دیپلوی روی **Railway**.

## ✨ قابلیت‌ها

- 🔒 **عضویت اجباری** در یک یا چند کانال قبل از استفاده از بات
- 🛒 **فروش پلن** با ساخت خودکار یوزر روی پنل و ارسال لینک اشتراک
- 🎁 **اکانت تست رایگان** (یک‌بار برای هر کاربر)
- 🎟 **کد تخفیف** (درصدی، با محدودیت تعداد استفاده و تاریخ انقضا)
- 💳 **کیف پول داخلی** با شارژ کارت‌به‌کارت و تایید دستی ادمین
- 📦 تاریخچه‌ی خرید هر کاربر
- ⚙️ **پنل مدیریت** داخل بات: آمار فروش، افزودن پلن، افزودن کد تخفیف، پیام همگانی
- 🎨 دکمه‌های رنگی واقعی تلگرام (آبی/سبز/قرمز) با استفاده از قابلیت جدید `style` روی دکمه‌ها

## 🔧 راه‌اندازی محلی (تست قبل از دیپلوی)

1. یک بات در [@BotFather](https://t.me/BotFather) بساز و توکن رو بگیر.
2. پنل PasarGuard خودت رو آماده کن و یک ادمین (username/password) برای اتصال API داشته باش.
3. فایل `.env.example` رو کپی کن به `.env` و مقادیر رو پر کن.
4. نصب و اجرا:

```bash
pip install -r requirements.txt
python bot.py
```

## ☁️ دیپلوی روی Railway

1. یک ریپازیتوری گیت‌هاب بساز و کل این پوشه رو داخلش push کن.
2. وارد [railway.app](https://railway.app) شو → **New Project → Deploy from GitHub repo**.
3. Railway به‌طور خودکار `Dockerfile` رو تشخیص می‌ده و ایمیج رو می‌سازه.
4. برو به تب **Variables** و همه‌ی متغیرهای داخل `.env.example` رو با مقادیر واقعی اضافه کن:
   - `BOT_TOKEN`, `ADMIN_IDS`, `FORCE_JOIN_CHANNELS`
   - `PANEL_URL`, `PANEL_USERNAME`, `PANEL_PASSWORD`, `PANEL_GROUP_IDS`
   - `CARD_NUMBER`, `CARD_HOLDER`, `CURRENCY`
   - `TRIAL_DAYS`, `TRIAL_GB`, `DB_PATH`
5. **مهم — پایدارسازی دیتابیس:** چون دیتابیس SQLite داخل فایل‌سیستم کانتینر ذخیره می‌شه و با هر ریدیپلوی پاک می‌شه، از تب **Volumes** یک والیوم بساز و آن رو به مسیر `/app/data` وصل کن (همون مسیر پیش‌فرض `DB_PATH=data/bot.db`).
6. دیپلوی رو بزن. لاگ‌ها باید پیام `Bot started, polling...` رو نشون بدن.

> بات با **long polling** کار می‌کنه، پس نیازی به دامنه یا HTTPS عمومی نداره و روی Railway بدون مشکل بالا میاد.

## 🎨 نکته‌ی دکمه‌های رنگی

پارامتر `style` روی `KeyboardButton` (مقادیر `primary` آبی، `success` سبز، `danger` قرمز) یک قابلیت نسبتاً تازه‌ی Telegram Bot API هست. اگر اپ تلگرام کاربر خیلی قدیمی باشه، ممکنه رنگ‌ها رو نشون نده و فقط دکمه‌ی معمولی ببینه — این مشکلی برای عملکرد بات ایجاد نمی‌کنه.

## ⚠️ نکات مهم قبل از استفاده‌ی واقعی

- **API پنل:** فایل `panel.py` بر اساس پکیج رسمی پایتون `pasarguard` نوشته شده. اگر نسخه‌ی پنل شما endpoint یا پارامترهای متفاوتی داشت، مستندات Swagger پنل خودت رو در آدرس `PANEL_URL/docs` چک کن و متد `create_vpn_user` رو مطابقش تنظیم کن.
- **تایید پرداخت:** فعلاً شارژ کیف پول با ارسال رسید و تایید دستی ادمینه (مناسب پرداخت کارت‌به‌کارت). اگر درگاه پرداخت آنلاین (زرین‌پال و غیره) می‌خوای، باید یک ماژول جدید برای همون درگاه اضافه بشه.
- **امنیت:** رمز پنل و توکن بات رو فقط در Variables ریلوی نگه‌دار، هرگز داخل کد commit نکن.
- **بک‌آپ:** به‌صورت دوره‌ای از فایل دیتابیس (`data/bot.db`) بک‌آپ بگیر.
